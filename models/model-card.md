# Паспорт модели (Model Card)

**Название:** Fish Weight Prediction (Linear/Ridge)
**Дата:** 27.10.2026
**Автор:** Клюкин Родион

## Назначение
Модель предсказывает вес рыбы на основе ее геометрических измерений (длина, высота, ширина) и вида.

## Данные
- **Источник:** `fish_participant.csv`
- **Признаки:** `Length3`, `Height`, `Width` (числовые), `Species` (категориальный).
- **Целевая переменная:** `Weight` (граммы).
- **Разбиение:** 80% / 20% (train/test), `random_state=42`. Выбросы удалены только из train по правилу IQR.

## Архитектура и предобработка
- `ColumnTransformer`: `SimpleImputer(median)` + `StandardScaler` + `FunctionTransformer(log1p)` для числовых. `SimpleImputer(most_frequent)` + `OneHotEncoder` для категориальных.
- Модель: `LinearRegression` (или `Ridge`) с логарифмированием целевой переменной (`TransformedTargetRegressor`).

## Метрики (на тестовой выборке)
- MSE: ~5215.69 (Linear) / ~5347.29 (Ridge)
- MAE: ~48.18 (Linear) / ~48.24 (Ridge)
- R²: ~0.953 (Linear) / ~0.952 (Ridge)

## Ограничения
- Модель чувствительна к выбросам (используется IQR).
- При сильной асимметрии (крупная рыба) возможна недооценка веса.
- Не рекомендуется применять к видам рыб, отсутствующим в обучающей выборке.
